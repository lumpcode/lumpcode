# Repo lumps

The lumps this repo runs on itself (`.lumpcode/lumps/`).

- `backlog` lump (`.lumpcode/lumps/backlog/`): big features; thin `featureBacklog({…})` wrapper (recipe emits `discoveryBranches` from `primaryDiscoveryBranch` / `itemDiscoveryBranchPrefix` defaults `dev` + `feature`, Cursor command, CLI build+test `implValidateCommand`)
- `docs` lump (`.lumpcode/lumps/docs/`): docs, naming, SEO, website copy; generic `backlog` recipe, implementation-only, `discoveryBranch: 'dev'`; does not wait on other lumps
- `qol` lump (`.lumpcode/lumps/qol/`): small quality-of-life; `featureBacklog` like `backlog` (CLI build+test)
- `bugfixes` lump (`.lumpcode/lumps/bugfixes/`): bugs; `featureBacklog` like `backlog` (CLI build+test)
- `ideasToBacklog` lump (`.lumpcode/lumps/ideasToBacklog/`): daily batch triage of root `IDEAS.yaml` (`{ name, task, blocked?, priority?, tags? }`; non-empty `blocked` skipped; `priority` lower = more important, triage prefers lower numbers and carries them into the chosen lane's `desc.yml` on promote; optional `tags` from the file-header allowlist; no required lane field) into one of four lumps (`backlog` \| `docs` \| `qol` \| `bugfixes`) via Cursor cloud agent (`@cursor/sdk`, `workOnCurrentBranch` + `autoCreatePR`); one UTC `YYYY-MM-DD` context when unblocked ideas exist; `maximumNumberOfConcurrentBranches: 1`; `discoveryBranch: 'dev'`; skill `.agents/skills/ideas-to-backlog/SKILL.md`; disabled only when **every** lane has more than 3 todo dirs; ops: dedicated daemon `--include=ideasToBacklog --cronSetup '<daily>'` and global `--exclude=ideasToBacklog`; `CURSOR_API_KEY` required on the worker. Interactive. The worker path that does not ask is `autoTriage`
- `autoTriage` lump (`.lumpcode/lumps/autoTriage/`): one UTC `YYYY-MM-DD` context when an unblocked `IDEAS.yaml` entry can land in a lane that has fewer than 5 `desc.yml` todos, or any lane todo is missing `requirements.md` (gate: `.lumpcode/helpers/workerQueue.ts`). Writes 1–5 top-level `desc.yml` + `requirements.md` with `workflow: [impl]` into `backlog` \| `docs` \| `qol` \| `bugfixes` so they run on the `dev` scan, or splits one large idea into that many slices that each stay buildable. Removes promoted ideas from `IDEAS.yaml`. Does not implement product code. `maximumNumberOfConcurrentBranches: 1`; `discoveryBranch: 'dev'`; skill `.agents/skills/auto-triage/SKILL.md`. Included in the global daemon (`ideasToBacklog` stays excluded)
- `bugHunter` lump (`.lumpcode/lumps/bugHunter/`): one UTC date context while `bugfixes` has fewer than 5 `desc.yml` todos. Reviews the tree, runs package tests, files 1–5 `bugfixes` items (`workflow: [impl]` + `requirements.md` with a repro) and does not fix them. After that PR merges, `bugfixes` implements them on the next `dev` scan. `maximumNumberOfConcurrentBranches: 1`; skill `.agents/skills/bug-hunter/SKILL.md`
- `polisher`, `writer`, `trimmer`: ephemeral contexts, `maximumNumberOfConcurrentBranches: 1`, `discoveryBranch: 'dev'`. Each lands one small change and `.lumpcode/lumps/<name>/explanation.md` (also the PR body via `explanationPrBody`). Polisher: behavior-preserving product polish, then `npm run build`. Writer: website and docs wording, following `.agents/memory/writing/`. Trimmer: one proven-unused or tautological piece, then `npm run build`. Skills: `.agents/skills/polisher/SKILL.md`, `writer/SKILL.md`, `trimmer/SKILL.md`
- `todoStackPrds` lump: `TODO.yml` / `DONE.yml` under `.lumpcode/lumps/todoStackPrds/`
- Version planning: `.lumpcode/lumps/v0.0.7/`, `v0.0.8/`, `v0.0.9/`
- `findAbstraction` lump (`.lumpcode/lumps/findAbstraction/`): ephemeral contexts hunt duplicated CLI logic; each run adds one util under `packages/apps/cli/src/utils/<name>/` (`main.ts`, `index.ts`, `unit.test.ts`, barrel) and refactors call sites so net line count drops; writes `<utilName>.abstraction.md` in the lump dir; validates with `npm run build -w=@lumpcode/cli && npm run test -w=@lumpcode/cli`
- `presetSmoke` lump (`.lumpcode/lumps/presetSmoke/`): TS smoke for presets/hooks (`command` tag + Cursor `model: 'auto'`; keep `disabled: true` except a one-off `lumpcode run`); swap the tag to try other presets
- Abstraction backlog (`abstractionImplementer` `backlogItems/todo|completed/<name>/desc.yml`): items are `name`, `task`, `priority`, optional `dependsOn` only — **no `type` field**; requirements live at `backlogItems/todo/<name>/requirements.md`; finder ephemeral context names via ISO-8601 timestamp in `ephemeralContextListFn` default naming (`:` stripped for valid context names)
- `backlog`, `qol`, and `bugfixes` pass `promptFns: learningsPromptFns(…)` from `.lumpcode/helpers/learningsPromptFns.ts`: every `featureBacklog` stage prompt (`req`, `testPlan`, `testImpl`, `impl`, `directImpl`) ends with an instruction to follow `.agents/skills/capture-learnings/SKILL.md` and write the item's `learnings.md`, which `update-memory` later mines. Stage-specific overrides (the `backlog` lane's `expect.yml` hint on `testImpl` / `impl`) go in as the helper's argument so learnings still wrap them. Shared lump code lives in `.lumpcode/helpers/` (included in `.lumpcode/tsconfig.json`), never in a config-less folder under `lumps/`
