# Ontology

What each entity is, why it exists, and how it relates to the others. Link to types and schemas. Do not paste them.

| File | Holds |
| --- | --- |
| `project.md` | A git repo with `.lumpcode/`; `project.json` versus `local.json` |
| `lump.md` | One campaign folder; config precedence, `disabled` |
| `context.md` | One unit of work; names, variables, dependencies |
| `context-status.md` | `toDo` / `branchPushed` / `finished` and the marker commit that decides it |
| `steps.md` | Prompts, commands, step functions, `contextRunState` |
| `command.md` | The agent a step runs: tag, module, or inline `CommandFn` |
| `workspaces.md` | Project, execution, and branch workspaces |
| `branches.md` | Primary, discovery, base, and work branches; lump lines |
| `worker-and-daemon.md` | Worker machine, daemon scheduler, tick, supervisor, transcript, dashboard |
| `recipe.md` | Recipe factories versus the kit |
| `backlog-item.md` | `desc.yml` items, tickets, and the files beside them (`requirements.md`, `expect.yml`, `learnings.md`) |
