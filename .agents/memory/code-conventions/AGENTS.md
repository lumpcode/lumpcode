# Code conventions

How we write, test, build, and release code in this repo. One file per convention family.

| File | Holds |
| --- | --- |
| `agent-skills.md` | Requirements, tickets, `expect.yml`, and how project skills are written and published |
| `build-and-release.md` | Git flow, CI, E2E, npm publishing, and worker VM scripts |
| `cli-conventions.md` | Command shape, flags, and what the CLI may touch on disk |
| `cli-framework.md` | Commander wiring, logging, `--json` envelopes, and the lump config types the CLI exposes |
| `code-style.md` | How code is written in this repo: function shape, results, scope, and where helpers live |
| `monorepo.md` | Packages, what each one publishes, and the stack |
| `testing.md` | How tests are written and where they live |
